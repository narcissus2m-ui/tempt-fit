01홈 화면에 앱 추가하기

앱 주소는 narcissus2m-ui.github.io/tempt-fit 입니다. 따로 앱스토어에서 받을 필요 없이, 휴대폰 홈 화면에 아이콘으로 추가해 두면 앱처럼 바로 열 수 있어요.

아이폰

  1. 사파리(Safari)로 위 주소를 엽니다.
  2. 화면 아래의 공유 버튼을 누릅니다.
  3. 목록을 내려 홈 화면에 추가를 누릅니다.
  4. 이름이 TEMPT FIT인지 확인하고 오른쪽 위 추가를 누릅니다.

안드로이드 (갤럭시 등)

  1. 크롬(Chrome)으로 위 주소를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴를 누릅니다.
  3. 홈 화면에 추가 (또는 앱 설치)를 누릅니다.
  4. 추가 또는 설치를 누르면 끝!

삼성 인터넷은 아래 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면을 누르세요.

홈 화면에 이 금색 하트 TEMPT FIT 아이콘이 생기면 성공이에요. 다음부터는 아이콘만 누르면 됩니다.

02가입하고 강사와 연결하기

  1. 앱을 열고 가입 → 나는에서 회원을 고릅니다.
  2. 이름, 이메일, 비밀번호(6자 이상)를 넣고 가입하기를 누릅니다.
  3. 처음 들어오면 강사와 연결 칸이 보여요. 강사에게 받은 6자리 초대 코드를 넣고 연결을 누릅니다.

강사가 미리 적어 둔 인바디·운동 기록과 수업 일정이 바로 내 화면에 나타나요. 강사가 여러 명이면 코드를 하나씩 더 넣으면 돼요 (내 정보 탭 › 내 강사 아래 초대 코드 입력).

코드가 아직 없다면내 기록 만들기로 혼자 먼저 시작해도 돼요. 나중에 코드를 넣으면 그동안 쓴 기록과 합쳐져요.

03화면 둘러보기

  • 홈: 오늘 일정, 보낸 요청, 남은 과제가 맨 위에 보이고, 그 아래 섭취 목표·인바디·회복·심박 요약이 있어요.
  • 일정: 위쪽 캘린더에서 강사와 잡힌 수업·보강, 과제 기한을 일간·주간·월간으로 보고, 과제에서 강사가 보낸 운동 과제를 하고 제출해요.
  • 운동: 캘린더, 기록하기, 운동 복기, 1RM 계산.
  • 영양: 하루 목표 열량과 탄단지를 봐요.
  • 분석: 심박 존 · 회복을 골라 봐요.
  • 내 정보: 위쪽 내 정보에 키·체중·목표와 인바디 기록, 내 강사에 연결된 강사 목록·강사 프로필·남은 세션이 있어요.

점선 밑줄이 있는 용어(RIR, 1RM 등)는 누르면 짧은 설명이 떠요.

04일정 보기 · 수업 일정 요청

오른쪽 위 숫자는 지금 보는 기간의 수업 · 보강 · 과제 개수예요.

  • 수업(금색): 끝나면 등록한 세션이 1회 줄어요.
  • 보강(초록): 서비스·보상 수업이라 세션이 줄지 않아요.
  • 노쇼(빨강, 줄 그음): 수업에 오지 않은 경우예요. 세션은 1회 줄어요.

수업 일정 요청하기

  1. 일간·주간 화면에서 원하는 시간의 빈 칸을 누릅니다.
  2. 강사가 여러 명이면 요청할 강사를 고릅니다.
  3. 날짜·시각을 확인하고 요청 보내기를 누릅니다.

강사가 승인하면 일정에 들어가고 알림이 와요. 강사가 시간을 바꿔 승인할 수도 있어요. 수업 일정은 강사만 직접 잡을 수 있어요.

05수업 취소 요청

  1. 일정에서 수업을 누르고 취소 요청을 누릅니다.
  2. 사유는 적어도 되고 비워도 돼요. 취소 요청 보내기를 누릅니다.
  • 강사가 승인하면 수업이 취소되고 세션은 줄지 않아요.
  • 강사가 확인하기 전에 수업 시간이 지나면 일단 세션이 줄고, 나중에 승인되면 다시 돌아와요.
  • 마음이 바뀌면 요청 거두기를 누르세요.

06과제 하고 제출하기

  1. 강사가 과제를 보내면 알림이 와요. 일정 탭 › 과제에서 과제를 누릅니다.
  2. 운동마다 정해진 무게·횟수·RIR(남겨 둘 반복 수)을 보고 운동한 뒤 하나씩 체크합니다.
  3. 인증 사진을 첨부하고(선택) 한 줄 메모를 남긴 뒤 완료 · 제출하기를 누릅니다.

제출하면 도장이 찍혀요.

  • 제출 완료: 기한 안에 제출
  • 지연 제출: 기한이 지난 뒤 제출
  • 미제출: 기한이 지났는데 아직 안 함 (지금이라도 제출할 수 있어요)

제출한 과제는 운동 기록에도 자동으로 들어가요.

07강사 탭

연결된 강사가 목록으로 보여요. 강사를 누르면 강사로서 철학 · 경력 · 자격과 이 강사와의 남은 세션 · 예정 수업 · 소진 기한을 볼 수 있어요.

연결을 끊으려면 강사 프로필 맨 아래 이 강사와 연결 해제를 누르세요. 앞으로의 일정은 지워지고, 내 기록은 남아요.

08알림

오른쪽 위 종 아이콘에 빨간 숫자가 뜨면 새 알림이 있어요. 새 일정, 일정 변경·취소, 요청 승인·거절, 새 과제를 알려 드려요. 알림을 누르면 그 일정이나 과제로 바로 가요.

09이용료

TEMPT FIT은 회원에게 무료예요. 구독이나 결제 없이 모든 기능을 쓸 수 있어요. 요금은 강사 구독만 있어요.

10자주 묻는 질문

비밀번호를 잊어버렸어요.
앱에서 직접 바꾸는 기능은 아직 없어요. 담당 강사에게 말씀해 주세요.
강사가 잡은 일정이 안 보여요.
사람 아이콘 › 서버에서 새로고침을 눌러 보세요. 강사 탭에 그 강사가 있는지도 확인하세요.
세션 수가 이상해요.
수업은 끝나는 시각이 지나야 1회 줄어요. 취소된 수업과 보강은 줄지 않아요. 그래도 다르면 강사에게 말씀해 주세요.
‘저장 실패’라고 떠요.
인터넷 연결을 확인하고 다시 저장을 누르세요.
