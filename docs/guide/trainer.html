01홈 화면에 앱 추가하기

앱 주소는 narcissus2m-ui.github.io/tempt-fit 입니다. 따로 앱스토어에서 받을 필요 없이, 휴대폰 홈 화면에 아이콘으로 추가해 두면 앱처럼 바로 열 수 있어요.

아이폰

  1. 사파리(Safari)로 위 주소를 엽니다.
  2. 화면 아래의 공유 버튼을 누릅니다.
  3. 목록을 내려 홈 화면에 추가를 누릅니다.
  4. 이름이 TEMPT FIT인지 확인하고 오른쪽 위 추가를 누릅니다.

안드로이드 (갤럭시 등)

  1. 크롬(Chrome)으로 위 주소를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴를 누릅니다.
  3. 홈 화면에 추가 (또는 앱 설치)를 누릅니다.
  4. 추가 또는 설치를 누르면 끝!

삼성 인터넷은 아래 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면을 누르세요.

홈 화면에 이 금색 하트 TEMPT FIT 아이콘이 생기면 성공이에요. 다음부터는 아이콘만 누르면 됩니다.

02가입 · 강사 프로필

  1. 가입 → 나는에서 강사를 고르고 이름·이메일·비밀번호를 넣습니다.
  2. 오른쪽 위 사람 아이콘 → 강사 프로필에 이름 또는 닉네임, 강사로서 철학, 경력, 자격을 적고 프로필 저장.

프로필은 연결된 회원의 내 정보 탭 › 내 강사에 그대로 보여요.

구독 전에는 잠겨 있어요강사는 가입은 바로 되지만, 구독 전에는 자물쇠 화면만 보여요. 아래에서 등급을 고르고 구독 신청을 누르면 마스터에게 알림이 가요. 마스터가 구독을 열면 열렸는지 확인을 눌러 바로 쓸 수 있어요. 결제 기능은 준비 중이에요.

구독 등급

등급월 구독료연결 회원
베이직8,900원5명
스탠다드12,800원10명
프로16,700원20명
무제한24,500원무제한
  • 회원 수는 회원 탭 목록 전체(아직 코드를 넣지 않은 회원 포함)로 세요. 다 차면 회원 추가가 막히고, 목록 위에 회원 X / N명이 보여요.
  • 무제한 등급이면 초대 코드로 연결된 회원의 구독료(월 500원)가 연결된 동안 감면돼요. 이미 구독 중이던 회원은 다음 결제일부터 감면돼요.
  • 등급을 바꾸려면 사람 아이콘 › 내 구독에서 등급을 고르고 변경 신청을 누르세요. 마스터가 확인하고 바꿔 드려요.

03회원 등록 · 초대 코드

  1. 회원 탭 → + 회원 추가 → 이름을 넣고 추가.
  2. 회원 정보 화면의 회원 앱 연결에 6자리 초대 코드가 생겨요. 회원에게 보내 주세요.
  3. 회원이 ‘회원’으로 가입한 뒤 코드를 넣으면 연결되고 알림이 와요. 이미 앱을 쓰던 회원이면 그 기록과 합쳐져요.

한 회원이 여러 강사와 연결될 수 있어요. 각 강사는 자기 수업·과제만 관리해요.

04새 수업 개설하기

  1. 회원 정보 화면 수업 · 세션 카드에서 + 새 수업 개설하기.
  2. 수업 수와 1회당 소진 기한(일)을 넣으면 소진 기한이 자동으로 계산돼요 (수업 수 × 1회당 일수). 날짜를 직접 바꿔도 돼요.
  3. 등록.

카드에 남은 세션 · 예정 수업 · 더 잡을 수 있는 수가 보여요. 다 쓰면 새 수업을 또 개설하면 돼요. 남은 세션보다 많이 잡으면 경고만 하고 잡을 수는 있어요. 기한이 지나면 기한 만료가 뜨고, 기한 연장으로 늘릴 수 있어요.

05일정 잡기 (일간·주간·월간)

  • 일간: 05시~00시, 1시간 칸. 칸의 위쪽 반은 정시, 아래쪽 반은 30분이에요. 빈 칸을 누르고 회원을 고르면 바로 잡혀요.
  • 주간: 월~일 7칸, 왼쪽에 시간 눈금. 일간과 똑같이 눌러서 잡아요.
  • 월간: 날짜마다 그날 일정이 미리 보여요. 날짜를 누르면 그날 일간으로 가요.

오른쪽 위에 지금 보는 기간의 수업 · 보강 · 과제 개수가 나와요.

잡은 일정을 누르면 10분 단위로 시각·길이를 바꾸고, 메모와 미리 할 운동(무게·횟수·RIR)을 적을 수 있어요. 보강은 세션을 쓰지 않는 서비스 수업이에요.

06여러 날 한꺼번에 잡기

  1. 일정 탭 아래 여러 날 한꺼번에 잡기에서 회원을 고릅니다 (회원 정보의 일정 잡기 (여러 날)도 같아요).
  2. 월간 달력에서 날짜를 누르면 05시~00시 30분 단위 시간이 나와요. 시간을 고릅니다.
  3. 다른 날짜를 누르고 시간 고르기를 반복합니다. 예: 1일 19:00, 8일 19:00, 11일 19:00 …
  4. 한꺼번에 등록. 회원에게는 알림이 한 번만 가요.

07세션 소진 · 노쇼 · 취소

  • 수업은 끝나는 시각이 지나면 세션 1회가 자동으로 줄어요.
  • 지난 수업을 누르고 노쇼 체크: 세션은 그대로 줄고, 그 시간에 다른 수업을 새로 잡을 수 있어요. 다시 누르면 노쇼가 풀려요.
  • 시작 전에 일정 취소: 세션이 줄지 않아요.
  • 지난 수업을 삭제: 줄었던 세션 1회가 돌아와요.

08회원 요청 승인

회원이 수업 일정 요청이나 취소 요청을 보내면 종 아이콘에 알림이 오고, 일정 탭 맨 위에 회원 요청이 떠요.

  • 승인 / 거절. 수업 일정 요청은 시각 바꾸기로 시간을 바꿔 승인할 수 있어요.
  • 취소 요청을 승인하면 수업이 취소되고 세션이 줄지 않아요. 승인 전에 수업 시간이 지났다면 승인할 때 다시 돌아와요.

09과제 주기

  1. 일정 탭 위쪽 과제 → + 과제 주기 → 회원을 고릅니다.
  2. 제목과 기한을 정하고, + 운동 고르기에서 운동을 여러 개 체크합니다.
  3. 운동마다 무게·횟수·RIR 세트를 정하고 과제 보내기.

회원이 제출하면 알림이 오고, 목록에 제출 완료 · 지연 제출 · 미제출 도장이 보여요. 인증 사진과 메모도 볼 수 있어요.

10운동 기록

지난 수업을 누르고 운동 기록 쓰기를 누르면 날짜·시각·미리 정한 운동이 채워진 기록 화면이 열려요. 무게·횟수를 고치고 저장하면 그 수업과 연결돼 남아요. 강사는 자기가 쓴 기록을 3일 안에 고칠 수 있어요.

11마스터

마스터 계정에는 마스터 탭이 더 있어요. 전체 강사와 회원 계정을 보고, 강사 구독 등급(베이직·스탠다드·프로·무제한)과 기간, 회원 구독(월 500원) 기간을 +1개월 / 해제로 정해요. 구독 전 강사는 잠금 화면만 보이고, 회원은 결제 연동 전까지 구독 없이도 모든 기능을 써요. 강사가 구독 신청을 보내면 종 아이콘에 알림이 와요.
