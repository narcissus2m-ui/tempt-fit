아이폰

  1. 사파리(Safari)로 위 주소를 엽니다.
  2. 화면 아래의 공유 버튼을 누릅니다.
  3. 목록을 내려 홈 화면에 추가를 누릅니다.
  4. 이름이 Crack GYM인지 확인하고 오른쪽 위 추가를 누릅니다.

안드로이드 (갤럭시 등)

  1. 크롬(Chrome)으로 위 주소를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴를 누릅니다.
  3. 홈 화면에 추가 (또는 앱 설치)를 누릅니다.
  4. 추가 또는 설치를 누르면 끝!
